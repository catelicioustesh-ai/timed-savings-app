# Timed Savings App

A mobile savings application built with **Flutter and Dart**, supported by a backend service developed using **Node.js and Express**. The application is designed to help users manage their savings, monitor their progress and access savings-related services.

## Project Overview

The Timed Savings App is a mobile application developed to make personal savings management easier and more accessible. It combines a Flutter-based mobile interface with backend services to support application functionality and financial transactions.

## Technologies Used

- **Flutter & Dart** – Mobile application development.
- **Node.js** – Backend development.
- **Express.js** – Backend API services.
- **M-Pesa Daraja API** – Mobile money integration and transaction testing.
- **Firebase** – Project configuration and supporting services.
- **Git & GitHub** – Version control and project management.

## Key Features

- User savings management.
- Savings tracking.
- Deposit functionality.
- Withdrawal functionality.
- Backend API integration.
- M-Pesa Daraja sandbox integration.
- Mobile application interface.

## Getting Started

### Prerequisites

Make sure you have installed:

- Flutter SDK
- Dart SDK
- Node.js and npm
- Visual Studio Code or another suitable IDE

### Running the Flutter Application

1. Clone the repository:

   ```bash
   git clone https://github.com/catelicioustesh-ai/timed-savings-app.git
   ```

2. Navigate into the project:

   ```bash
   cd timed-savings-app
   ```

3. Install Flutter dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

### Backend Configuration

1. Navigate to the backend directory.
2. Install the required Node.js dependencies.
3. Configure the environment variables using the provided `.env.example` as a reference.
4. Add your own development credentials.
5. Start the backend using its configured start script.

**Important:** Never upload real API keys, M-Pesa credentials, passwords or private keys to GitHub.
